# BA4L approved design system

Approved September12: combine conceptA Score First and conceptB Team Night from generated board exec-884d2ac9-0d47-4470-b90b-d184a7a53b07.png.

Identity: bold custom4 with bowling hook, one recognizable emblem. BA4L athletic slab wordmark, expanded Big Al’s4Life lockup when useful. No tiny caption inside Home Screen icon, fine ring, invented crest/year or new mascot. Bowling Bro’ is an endorsed feature.

Palette: forest #203B2F, warm ivory #F4F1E8, restrained lime #DDF29A. Web uses ivory surfaces, forest score areas and strong tabular actual scores. iOS respects system light/dark with semantic assets; SF fonts for scalable controls, club character in the brand wordmark. Native TabView/NavigationStack remain.

Score First: compact bowler/frame context, actual score primary, attainable finish secondary. Pin input and Undo together before long history/setup. Stable numeric keypad, scan/voice adjacent and directly opened from mode links. iPad persistent team rail with score/detail workspace.

Team Night: state-aware current/pre-bowl/final dashboard, explicit game/series point labels, team totals and dated standings. Finished nights prioritize review/results. Shared data must remain truthful.

Use crisp borders, purposeful groupings, 12–16pt radii, generous touch targets, readable secondary labels. Honor Dynamic Type, keyboard, VoiceOver, reduced motion and safe areas. Generated screenshot typography and numeric samples are direction only; implement real data and native controls.

September 12 refinement: add muted gold #D8B86A for selected scoring actions, coaching cues and result highlights. Use pale gold #F4E8C8 for quiet insets and dark gold #795B24 for text on ivory. Keep lime confined to the established logo; forest and ivory remain dominant. Gold never replaces error or warning labels. Native gold assets include dark/high-contrast variants.

September 12 appearance sweep: all filled brand surfaces require paired adaptive foreground tokens. GoldSurface uses OnGoldSurface, never fixed forest text. Tonight uses a full-bleed HomeBackground with content respecting native safe areas. Dark Mode uses a deeper forest canvas, elevated forest cards and muted gold action tint; lime stays in the mark. Current results precede idle camera status. Validate light/dark and increased contrast with ios/Tests/theme-contrast.ts before shipping asset changes.
